# cards-author-bio

Custom **cards** block. Purpose: Article author bios with photo, name, role and expandable bio.

## Authoring (Document Authoring)

Model: `cards`

Single block table. Content: row 1: heading text (block field); then one row per author: cell 1 photo, cell 2 name (H3), role paragraph, bio paragraphs.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

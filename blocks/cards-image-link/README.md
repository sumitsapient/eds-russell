# cards-image-link

Custom **cards** block. Purpose: Image cards (image, title, description) where the entire card is a single link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1: image; cell 2: title (heading or bold paragraph), description, link. The first link becomes the card link..

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

# columns-media

Custom **columns** block. Purpose: Text column (subheadings, descriptions, CTA) side by side with a photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; cells: text cell (h3 + paragraphs + CTA link) and image cell, in either order.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

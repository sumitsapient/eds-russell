# toc-article

Custom **toc** block. Purpose: Sticky article table of contents linking to the article's H2 sections.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: single row, single cell: heading text (optional, defaults to 'Table of contents').

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

# carousel-timeline

Custom **carousel** block. Purpose: Horizontally scrolling timeline of milestone slides with prev/next navigation.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cells: icon image, text (year paragraph + h3 milestone).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

# columns-promo-panel

Custom **columns** block. Purpose: Boxed promo text (eyebrow, heading, paragraph, CTA) beside an edge-to-edge image; dark option renders a full-bleed navy band.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: text cell (optional eyebrow paragraph, H3, paragraph, CTA link) and image cell, in either order.

## Supported variations

| Variation | Option class |
| --- | --- |
| Dark | `dark` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Dark.
